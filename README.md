# Agri Export Co. — Business Website Demo

Agri Export Co. is a fictionalized business website demo created to showcase frontend development, responsive design, and professional business website implementation.

All company information, branding, contact details, imagery, and location information in this public demo are fictional and created for portfolio purposes.

## Overview

This project demonstrates a professional agricultural export website experience, including product presentation, quality/process information, facility visuals, export-focused content, regional presence, and contact/inquiry UI. The demo is built as a single-page site with a modern, clean design and a fully responsive layout.

## Features

- Responsive design
- Mobile navigation
- Product showcase
- Product gallery
- Quality/process section
- Facility showcase
- Export-focused sections
- Regional Gujarat map
- Contact/inquiry section
- Scroll reveal animations
- SEO and Open Graph metadata
- Accessible image alt text

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
